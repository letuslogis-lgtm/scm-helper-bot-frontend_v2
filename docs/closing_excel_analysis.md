### 1. 브랜드별 출고실적금액 (outbound_order)

- **헤더 행**: 첫 번째 데이터 행에서 식별 필요

- **특이사항**: 한 시트에 여러 표가 존재하는 복합 구조

### 2. CUT금액/직송금액 (cut_picking / direct_cut)

- **주요 컬럼**:
  - 품목ID: `코드-색상` combined (단일 컬럼)
  - `(22)` CUT금액 ← 핵심
- **특이사항**: 용역료 기반 계산, ITEM ID가 "코드-색상" 합산 문자열

### 3. 양지3센터 브랜드별 피킹금액 (wms_wave)

- **주요 컬럼**:
  - 품목ID: `코드-색상` combined (단일 컬럼)
  - `(15)` 피킹금액 ← 핵심
- **특이사항**:

  - WAVE 분류: 수주건명 컬럼에서 파싱
  - AS(경인)→false, AS(지방)→true, 경인(소액)→false 등 WAVE 적합성 규칙 적용

## 공통 처리 사항

### JS Date 문자열 파싱
모든 파일의 날짜 컬럼이 아래 형식:
```
"Tue Mar 31 2026 23:59:08 GMT+0900 (한국 표준시)"
```
파싱 방법:
```javascript
const d = new Date(dateStr);
// 또는
const match = dateStr.match(/(\w{3} \w{3} \d{2} \d{4})/);
```

### 품목ID 조합 방식
| 파일 | 코드 컬럼 | 색상 컬럼 | 조합 방식 |
|---|---|---|---|
| 출고실적금액 | 별도 | 별도 | 코드 + "-" + 색상 |
| CUT/직송 | combined | - | 그대로 사용 |
| 피킹금액 | combined | - | 그대로 사용 |
| 반품실적 | (6) | (7) | 코드 + "-" + 색상 |
| 입고실적 | (4) | (5) | 코드 + "-" + 색상 |

### 합계 행 처리
- **피킹금액**: 마지막 행 = 합계 → `slice(0, -1)` 또는 번호 컬럼이 비어있으면 skip
- **반품실적**: 번호(0) 컬럼이 숫자인 행만 처리
- **입고실적**: 번호(0) 컬럼이 숫자인 행만 처리
